# Pasta de Sons do Sistema

Para usar um som personalizado de campainha no painel de chamadas, coloque um arquivo de áudio aqui com o nome:

**dingdong.wav**

Requisitos:
- Formato: WAV
- Duração recomendada: 1-2 segundos
- Taxa de amostragem: 44100 Hz

Se o arquivo não existir, o sistema irá gerar um som de campainha sintético automaticamente.
